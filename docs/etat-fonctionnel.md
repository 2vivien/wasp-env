# État fonctionnel de la révision

Cette page décrit l’écart entre le cahier des charges MVP (`docs/00` à `docs/13`) et l’application présente dans ce dépôt. Les éléments marqués « partiel » ont une API et un écran, mais pas encore tous les tests, états ou contrôles exigés.

| Domaine     | Disponible dans cette révision                                                                                                                                                                                            | À construire / valider                                                                            |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Socle       | Tokens Vercel, coquille sidebar/topbar/mobile, palette `⌘K`, pages système, proxy, CSP nonce, migrations Drizzle, erreurs normalisées, permissions, rate limiting, CI, Husky, gitleaks, Prettier, Playwright, licence MIT | Couverture 95 %, audit externe, RLS ou équivalent vérifié, budgets de performance                 |
| Connexion   | Google, pseudo vérifié en direct, onboarding reprenable, `/unlock`, phrase et récupération                                                                                                                                | `email_verified` explicite, handle modifiable 1×/30 j, rotation des enveloppes branchée dans l’UI |
| Coffres     | Coffres multiples, métadonnées chiffrées, archivage/restauration/corbeille, membres, rôles, permissions, transfert, départ, rotation API                                                                                  | Rotation réelle des blobs par lots, journaux d’usage de rotation, UI de progression complète      |
| Secrets     | Métadonnées structurées chiffrées, catégories, tags, notes, favoris, archivage, duplication, version diff masquée, générateur                                                                                             | Champs par catégorie complets, déplacement entre coffres, favoris en table dédiée                 |
| Projets/ENV | Projets chiffrés, environnements, kanban avec copie/déplacement et alternative clavier, comparateur sans valeurs, import multi-fichiers, export fidèle                                                                    | Historique ENV, virtualisation, `@dnd-kit`, comparaison sur deux environnements multiples         |
| Partage     | Coffre, partages ciblés secret/projet, liens + QR + code, groupes, invitations dédiées, permissions atomiques, journaux d’usage                                                                                           | Empreintes/TOFU, exceptions complètes côté API, rotation projet, invitations par lien             |
| Réglages    | Apparence, thème, densité, délais, sessions, activité, sauvegarde chiffrée                                                                                                                                                | Régénération de clé de récupération branchée, alertes de sécurité, i18n complète                  |

Avant d’annoncer une fonction comme terminée, ajouter son interface complète, son endpoint autorisé, ses états et ses tests.
